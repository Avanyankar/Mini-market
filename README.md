# Мини-маркет

Учебный книжный магазин на Vite, React, TypeScript и styled-components. В каталоге 12 книг, поиск по названию и автору и фильтр по жанру. Корзина и выбранная тема сохраняются в браузере. Оформление заказа имитируется локально.

[Открыть магазин на GitHub Pages](https://avanyankar.github.io/Mini-market/)

## Локальный запуск

Требуются Node.js 24 и npm.

```bash
npm ci
npm run dev
```

```bash
npm test            # Unit- и интеграционные тесты
npm run build       # Проверка TypeScript и сборка в dist/
npm run preview     # Просмотр production-сборки по пути /Mini-market/
```

При пуше в `main` GitHub Actions запускает тесты, собирает приложение и публикует `dist/` на GitHub Pages.

## styled-components против CSS Modules на моём проекте

Расширение `DefaultTheme` задаёт единую структуру токенов для трёх палитр и проверяет обращения к ним при компиляции TypeScript.
При смене темы `ThemeProvider` обновляет значения в контексте React, а styled-components пересчитывает зависящие от темы правила.
Пропсы `$variant`, `$size` и `$loading` управляют стилями кнопки и исключаются из атрибутов DOM.
Динамические интерполяции и вставка правил добавляют расходы во время выполнения.
В варианте с CSS Modules классы формируются при сборке, а переключение палитры можно реализовать через CSS-переменные и атрибут темы на корневом элементе.
